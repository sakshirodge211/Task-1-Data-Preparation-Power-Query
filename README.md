# Task 1 – Business Sales Data Preparation using Power Query

## Project Overview

This project focuses on preparing and cleaning a business sales dataset for Power BI analysis.

The raw dataset contains sales transactions with information about orders, customers, products, regions, payment methods, discounts, sales, costs, and order status.

The data was cleaned and transformed using **Microsoft Power BI – Power Query Editor** to make it accurate, consistent, and ready for analysis.

## Tools Used

- Microsoft Power BI
- Power Query
- Excel/CSV
- GitHub

## Dataset

The dataset contains business sales transaction records with the following fields:

- Order_ID
- Order_Date
- Customer_Name
- Category
- Region
- Sales_Channel
- Quantity
- Unit_Price
- Discount
- Sales_Amount
- Cost_Amount
- Payment_Method
- Order_Status

## Data Cleaning & Transformation

The following transformations were performed in Power Query:

1. Promoted the first row as column headers
2. Corrected column data types
3. Removed duplicate records
4. Removed blank rows
5. Trimmed unnecessary spaces
6. Cleaned text values
7. Handled missing values
8. Standardized text fields
9. Checked for errors and empty values
10. Prepared the final dataset for Power BI analysis

## Power Query Transformation Steps

The main transformation steps can be viewed in the **Applied Steps** section of Power Query.

Example:

`Source → Promoted Headers → Changed Type → Removed Duplicates → Removed Blank Rows → Trimmed Text → Cleaned Text → Replaced Values`
